# Karta Kontenta Design Quality Rubric

Перед завершением любой визуальной задачи оцени результат по 100-балльной шкале.

## 1. Бренд и настроение — 20 баллов

Проверь:

- выглядит ли это как аккуратный creator SaaS;
- есть ли ощущение порядка в контенте;
- не похоже ли на CRM;
- не похоже ли на generic template;
- не слишком ли много фиолетового или декоративности.

Оценка:

- 0-5: выглядит как обычная CRM или сырой шаблон.
- 6-10: базово аккуратно, но без характера продукта.
- 11-15: красиво, но не хватает ощущения карты/системы.
- 16-20: выглядит как сильный рабочий бренд для контент-воронок.

## 2. Ясность продуктового сценария — 20 баллов

Проверь:

- понятно ли, где продукты;
- понятно ли, где контент;
- понятно ли, где CTA/кодовое слово;
- понятно ли, как собирается воронка;
- видна ли связь между сущностями.

Оценка:

- 0-5: сценарий непонятен.
- 6-10: сценарий есть, но экран надо расшифровывать.
- 11-15: в целом понятно, но есть лишний шум.
- 16-20: пользователь быстро понимает систему и следующий шаг.

## 3. Mobile first и компактность — 20 баллов

Проверь:

- нет ли горизонтального scroll;
- поля и dropdown не слишком высокие;
- чипы компактные;
- модалки не требуют лишней прокрутки;
- Telegram Mini App viewport не ломает вёрстку.

Оценка:

- 0-5: mobile разваливается.
- 6-10: работает, но слишком много воздуха.
- 11-15: хорошо, но можно плотнее и аккуратнее.
- 16-20: mobile выглядит как основной продуманный интерфейс.

## 4. UI-система — 20 баллов

Проверь:

- чипы, кнопки, поля, dropdown, фильтры выглядят едино;
- edit mode через gear/check понятен;
- delete требует подтверждения;
- validation подсвечивает конкретные пропуски;
- иконки одного стиля.

Оценка:

- 0-5: элементы разрозненные.
- 6-10: базово работает, но визуально не собрано.
- 11-15: красиво, но есть несостыковки.
- 16-20: цельная компактная дизайн-система.

## 5. Композиция и адаптив — 20 баллов

Проверь:

- нет ли огромных пустых провалов;
- страницы не выглядят как длинный лендинг;
- карточки не вложены без смысла;
- пустые состояния помогают;
- desktop и mobile читаются.

Оценка:

- 0-5: композиция развалена.
- 6-10: работает, но рыхло.
- 11-15: хорошо, но можно собрать плотнее.
- 16-20: композиция сильная и спокойная.

## Порог качества

Если итоговая оценка ниже 85/100 — не завершай работу, а сам предложи и внеси улучшения.

Если ниже 75/100 — результат нужно считать черновиком, не финалом.

Цель для ключевых экранов:

- mobile create product: 90+/100;
- mobile create content: 90+/100;
- mobile create funnel: 90+/100;
- products/content/funnels pages: 85+/100;
- admin panel: 85+/100.
