# Karta Kontenta Reference Analysis

## Эталонное направление

Основной визуальный референс «Карты контента»:

Compact creator SaaS / content-funnel workspace / Telegram Mini App utility / clean visual map UI.

Это не CRM, не тяжёлый dashboard, не обычный календарь постов и не лендинг.

Главная идея визуала:

> понятная карта продуктов, контента, CTA и воронок + спокойный рабочий слой управления.

## Что должно чувствоваться

- чисто;
- спокойно;
- собрано;
- компактно;
- технологично;
- не перегружено;
- понятно на мобильном;
- рабочий инструмент, который наводит порядок;
- карта, где видно, как контент ведёт к продуктам.

## Главный герой интерфейса

Не dashboard.

Не таблица.

Не набор случайных карточек.

Главный герой — связанная система:

- контекст;
- продукты;
- темы;
- контент;
- CTA/кодовые слова;
- воронки;
- карта;
- календарь.

Рабочие функции должны помогать видеть связи, а не превращать экран в набор форм.

## Что нравится в текущем направлении

- светлый интерфейс;
- фиолетовый как понятный акцент;
- чипы типов продукта;
- нижняя мобильная навигация;
- идея карты связей;
- связка продукты -> контент -> воронки;
- Telegram Mini App как быстрый кабинет;
- возможность редактировать пользовательские типы/форматы/площадки.

## Что нельзя терять

- понятность рабочего цикла;
- компактность на мобильном;
- мягкие белые поверхности;
- тонкие серые линии;
- выбранные состояния через soft violet;
- визуальную связь между продуктами, контентом и CTA;
- возможность быстро создать объект без бесконечной прокрутки;
- спокойный, полезный UI без маркетинговой декоративности.

## Что нужно улучшать относительно текущих черновиков

- не делать огромные поля с маленьким текстом;
- не растягивать dropdown строки;
- не создавать горизонтальный scroll в меню;
- не держать лишние helper-фразы вроде `Выберите слово...`, если поле уже понятно;
- не делать шестерёнки отдельными странными блоками;
- не показывать delete-кнопки в обычном режиме;
- не оставлять disabled submit без подсветки недостающих полей;
- не делать админку из фейковых метрик;
- не делать мобильные модалки слишком воздушными.

## Формула хорошего результата

Если пользователь открывает мобильное приложение в Telegram, он должен подумать:

«О, я быстро понимаю, где продукты, где контент, где воронка и что нужно заполнить».

А потом:

«И это выглядит аккуратно, не как таблица и не как хаос».

## Главная проверка

Хороший интерфейс «Карты контента» отвечает на три вопроса:

1. Что я продаю?
2. Каким контентом я веду к продаже?
3. Через какое CTA/слово это связано в воронку?
