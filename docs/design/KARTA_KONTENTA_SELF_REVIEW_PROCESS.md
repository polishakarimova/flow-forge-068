# Karta Kontenta Self Review Process

Перед любой дизайн-задачей Codex должен:

1. Прочитать:
   - `AGENTS.md`
   - `docs/design/KARTA_KONTENTA_BRAND_GUIDE.md`
   - `docs/design/KARTA_KONTENTA_UI_RULES.md`
   - `docs/design/KARTA_KONTENTA_REFERENCE_ANALYSIS.md`
   - `docs/design/KARTA_KONTENTA_DESIGN_QUALITY_RUBRIC.md`
   - `docs/design/KARTA_KONTENTA_VISUAL_CHECKLIST.md`
   - `docs/design/KARTA_KONTENTA_DO_NOT_REPEAT.md`

2. Сформулировать кратко:
   - какой экран меняет;
   - какие компоненты затрагивает;
   - какие дизайн-принципы применяет;
   - что нельзя сломать.

3. После реализации сделать self-review.

Комментарий:

### UI-система

Оценка: X/20

Комментарий:

### Композиция и адаптив

Оценка: X/20

Комментарий:

### Итог

Общая оценка: X/100

Если меньше 85/100:

- перечислить слабые места;
- внести исправления;
- повторить оценку.

## Правило

Нельзя завершать дизайн-задачу словами «готово», если не сделан self-review.

Для design-doc-only задач self-review по визуальному результату не нужен, но нужно подтвердить, что сайт, страницы, компоненты, API и база не менялись.
