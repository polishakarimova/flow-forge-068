# Утверждение дневных серий — 30 сентября 2026

Изменены только календарь публикаций, управление дневной серией и API утверждения. Существующая навигация, редактор, история текстов и ручные отметки сохранены. Форматы сгруппированы; одна кнопка утверждает все материалы выбранного формата на выбранную дату.
