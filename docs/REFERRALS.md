Профиль: аккаунт Telegram, баланс и история в отдельном окне, приглашение по постоянной ссылке, подключённые агенты, переходы к продуктам/материалам/воронкам и обучение. ## Условия

- Награда только пригласившему, 50 лайков, один раз за нового пользователя.
- Запуск бота и подтверждение в боте не завершают авторизацию. Начисление происходит при выдаче сессии приложению.
- Браузер: первый источник хранится 30 дней; login request хранит код, привязанный к браузеру. Подписанные Mini App start_param и ref_ в /start также поддерживаются. Первый действующий источник бота имеет приоритет над последующим переходом сайта.
- Старый/перенесённый аккаунт, самоприглашение, повторный вход, второй запрос и неизвестный код бонуса не дают. Новый профиль создаётся при подтверждении в боте, но его право на первый вход сохраняется до завершения входа в приложение.
- Начисление, погашение login token и сессия фиксируются одной транзакцией. Сбой откатывает все три действия. Строчная блокировка и уникальный invited_user_id защищают одновременные входы. Перезапуск не меняет баланс.
- Публичный ответ содержит только собственные итог/историю, без имён и Telegram ID приглашённых. API требует действующую сессию; заголовки no-store и штатная защита запросов сохранены.
- Новый код создаётся один раз; баланс и история хранятся на PostgreSQL. Браузер хранит только источник перехода.
