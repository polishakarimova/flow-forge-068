# Три объединённых варианта пунктов 5 и 6

Изолированные интерактивные макеты «Карты контента»: пошаговый старт, маршрут от продукта и недельная доска. Каждый содержит пять шагов старта, редактируемые примеры, ручные результаты, помощь, экспорт и состояния подключений. Примеры условные, состояние хранится только в памяти страницы. Рабочий API и пользовательские данные не используются.

Запуск из корня: `npx vite --config previews/vite.config.ts`. Адрес: http://127.0.0.1:5178/. Отдельная сборка: `npx vite build --config previews/vite.config.ts`. `node previews/package-preview.mjs <путь.html>` собирает результат в самостоятельный HTML. Основная сборка приложения эти экраны не включает.

Проверены TypeScript, ESLint и сборка; в браузере — шаги, выбор примера, 0 против пустого результата, фактическое скачивание условного JSON, ширины 360/390/430/1280 px. Настоящая клавиатура Telegram/iOS не проверена. До внедрения выбранного варианта потребуется реализовать серверное сохранение, полный экспорт/импорт, поддержку и путь удаления; макет их не запускает.

Применены документы docs/design. Самопроверка (бренд / сценарий / mobile / UI-система / композиция): вариант 1 — 18/19/18/18/18 = 91; вариант 2 — 18/19/18/17/17 = 89; вариант 3 — 18/18/18/17/17 = 88. Это авторская оценка макетов, не пользовательский тест. Вариант 1 предложен первым благодаря ясному следующему шагу на телефоне; окончательный выбор за Полиной.
